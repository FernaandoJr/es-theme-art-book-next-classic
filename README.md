# Art Book Next Classic

Hybrid EmulationStation theme for ArkOS:

| Screen | Source (copied as-is) |
|--------|------------------------|
| **System list** | [Art Book Next ArkOS](https://github.com/nkahoang/es-theme-art-book-next-arkos) |
| **Gamelist** | [Art Book 3:2](https://github.com/Jetup13/es-theme-art-book-3-2) |

Both based on **Anthony Caccese**’s Art Book / Art Book Next.

## Install

Copy folder to `/roms/themes/es-theme-art-book-next-classic` (or `H:\themes\` from Windows).

Start → UI Settings → Theme → `es-theme-art-book-next-classic` → Aspect **4:3** (R36H).

## Device customizations

Besides this theme, the handheld also has boot logo, Plymouth, ES splash, and launch-image tweaks.

See **[CUSTOMIZATIONS.md](./CUSTOMIZATIONS.md)** for the full list (paths, scripts, binary patches, how to revert).

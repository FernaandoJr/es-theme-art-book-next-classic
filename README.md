# Art Book Next Classic

Hybrid EmulationStation theme for ArkOS (R36H and similar):

| Screen | Source |
|--------|--------|
| **System list** (carousel, artwork styles, color schemes) | [Art Book Next ArkOS](https://github.com/nkahoang/es-theme-art-book-next-arkos) |
| **Gamelist** (list + cover, metadata layouts, grid) | [Art Book 3:2](https://github.com/Jetup13/es-theme-art-book-3-2) |

Both upstream themes are based on work by **Anthony Caccese** ([art-book-next-es](https://github.com/anthonycaccese/art-book-next-es) / Art Book).

## Install (ArkOS)

1. Copy this folder to `/roms/themes/es-theme-art-book-next-classic` (or `H:\themes\` on the SD card from Windows).
2. On the device: **Start → UI Settings → Theme** → `es-theme-art-book-next-classic`.
3. Set **Aspect Ratio** to **4:3** on R36H (640×480).
4. Optionally set **System View: Style** and **Gamelist View Style** under Theme Configuration.

## Options

- **Aspect Ratio** — 16:9, 16:10, 4:3, 3:2, 5:3, 1:1 (4:3 prioritized for R36H)
- **Color Scheme** — Art Book Next, Art Book, Steam OS, SNES, Famicom, Black, Grayscale
- **System View: Style** — Multi / Centered / No Artwork / Custom variants (from Next)
- **Gamelist View Style** — No Metadata, Minimum, Maximum, Flipped, Media Only, Polymega (from Art Book classic)
